# Refactoring Walkthrough: Planner-Generator-Evaluator アーキテクチャ

toioの自律制御ロジックを、より複雑な多段階タスクに対応できる「Planner-Generator-Evaluator」の3層構造へとリファクタリングしました。

## 変更内容

### 1. Planner フェーズ (Phase 1)
ユーザーの指示を解析し、複数の具体的なステップに分解した「タスクリスト」を最初に作成します。
- **場所**: `js/agent-loop.js`
- **特徴**: JSON形式で `tasks` 配列を生成し、全体の実行計画を立てます。

### 2. Generator フェーズ (Phase 2)
現在のタスクを達成するための具体的な行動（ツール呼び出し）を生成します。
- **特徴**: 前のフェーズで作成された「全体の計画」をコンテキストとして持ち、一貫性のある行動を可能にします。

### 3. Evaluator フェーズ (Phase 3)
実行後の状態（座標、角度など）を、現在のタスクの「自然言語での説明」と照らし合わせて評価します。
- **特徴**: 単なる座標の距離チェックだけでなく、回転やLED、音などの非空間的なタスクも評価可能です。

### 4. イテレーションロジックの改善
- 試行回数の制限を「1つのタスクあたり最大3回」のように個別に設定しました。
- これにより、全体で回数が枯渇して途中で止まるリスクを減らし、各ステップを確実に完了させることを目指します。

## 動作確認のお願い

ブラウザをリロードし、以下のような「段階的な指示」を試してみてください。

> **プロンプト例:**
> 「座標 (300, 300) に移動して、そこで360度回転して、最後に (500, 500) に向かって」

### 確認ポイント
1. UI上のログに「行動計画を立案中...」と表示され、複数のタスクが生成されること。
2. タスクが1つずつ順番に実行（Acting）と評価（Thinking: 達成状況を評価中...）を繰り返しながら進行すること。
3. 全てのステップが終わると「全てのタスクを終了しました。」と表示されること。

> [!IMPORTANT]
> ブラウザのリロードをお忘れなく。動作中にコンソール（F12）でエラーが発生した場合は、その内容を教えてください。
