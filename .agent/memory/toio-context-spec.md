# toio エージェント・コンテキスト仕様

このドキュメントでは、toio を操作する AI エージェント（Gemma 4 等）に対し、どのような情報が提供され、どのようなルールが適用されているかを記述します。

---

## 1. システムプロンプト (Role & Behavior)

エージェントの基本的な人格と行動指針を定義します。

### 役割の定義
- **名称**: toio キューブ操作アシスタント
- **目的**: ユーザーの指示に従い、小型ロボットキューブ「toio」をマット上で動かし、インタラクションを行う。

### 応答スタイル
- 落ち着いた、簡潔な日本語を使用。
- 過剰な丁寧語や感嘆符（「！」）、大げさな表現を避ける。
- 事実を淡々と伝え、冗長な前置きを排除する。

### 基本行動ルール
1. **計画**: 複雑な指示は `think` ツールを使用して計画を立ててから実行する。
2. **評価**: アクション実行後は必ず結果を確認し、必要に応じて追加アクションを行う。
3. **情報活用**: 提供される環境情報（位置・状態）と空間情報を常に参照する。
4. **報告**: 目標達成時はツールを呼び出さず、テキストで結果を報告する。
5. **安全**: マットの端に近い場合は慎重に動き、落下を低減させる。
6. **座標系**: 位置関係や距離の把握にはすべて「座標単位（Position IDユニット）」を使用し、物理単位（mm/cm）への換算は行わない。

---

## 2. 空間情報 (Spatial Context)

エージェントが「車両感覚」を持って移動するための空間データです。

### 静的情報 (Static Guide)
システムプロンプトに一度だけ注入されます。
- **座標範囲**: X(98〜402: 幅304単位), Y(142〜358: 高さ216単位)
- **キューブサイズ**: 約 24 × 24 単位 (マット幅の約 7.8%)
- **移動の目安 (speed=50 の場合)**:
    - 300ms ≈ 26 単位
    - 700ms ≈ 59 単位
    - 1500ms ≈ 126 単位
    - 端から端: 約 304 単位 (X方向) / 約 216 単位 (Y方向)
- **回転の目安 (speed=50 の場合)**:
    - 90度: 約 280ms
    - 180度: 約 560ms
    - 1回転: 約 1120ms

### 動的情報 (Dynamic Context)
毎回の推論ループで「現在の環境状態」として注入されます。
- **座標系**: Simple Play Mat の Position ID 座標 (x: 98~402, y: 142~358)
- **現在位置と角度**: 例 `現在位置: (250, 250), 角度: 0°`
- **マット端までの余裕**: 上下左右の端までの距離（座標単位）
- **安全警告**: いずれかの端まで 30 座標ユニット未満になった場合、`⚠️ 警告: マット端に接近しています。` が表示される。

---

## 3. 記憶情報 (Memory Context)

セッションを跨いだ継続性を維持するための情報です。

### 短期記憶 (Summaries)
- 直前のセッションの実行内容を 1 文で要約したもの。
- 例: `前回のセッションの要約: ユーザー: "前進して" / 最終状態: ツール実行完了`

### 永続的な記憶 (Facts)
- ユーザーから明示的に教えられた事実や設定。
- キー・バリュー形式で保持される。

---

## 4. ツール仕様 (Capabilities)

エージェントが実行できるアクション（Tool Use）の定義です。

| ツール名 | 説明 | 主要な引数 |
| :--- | :--- | :--- |
| `think` | 段階的な思考や計画の作成 | `thought` (string) |
| `get_position` | 最新の位置と端までの余裕を取得 | - |
| `move_to` | 指定した絶対座標および角度へ移動 | `x`, `y`, `angle` |
| `move_path` | 複数座標を順番に経由する移動 | `waypoints` (array) |
| `spin` | 中心軸で回転（ダンス等） | `direction`, `duration_ms` |
| `stop` | 全ての移動を即座に停止 | - |
| `set_light` | キューブの LED 色を変更 | `red`, `green`, `blue`, `duration_ms` |
| `set_light_pattern` | 複数色のLEDアニメーションパターン再生 | `frames` (array), `repetitions` |
| `play_sound` | 効果音やMIDI音を再生 (単音) | `note_id`, `duration_ms` |
| `play_melody` | 複数のMIDI音符を指定時間で連続再生 | `notes` (array) |
| `wait` | 指定時間待機 | `duration_ms` |
| `get_battery` | バッテリー残量(0-100)を取得 | - |

---

## 5. 注入プロセス

1.  **システムメッセージの構築**:
    - [役割/ルール] + [Static Guide] + [Memory Context]
2.  **ユーザーメッセージの拡張**:
    - `[SYSTEM INJECTION: 現在の環境状態]` + [Dynamic Context]
    - `[USER MESSAGE]` + [ユーザー入力]
3.  **推論ループ**:
    - LLM がツール実行を決定 -> `tool-executor` が物理/シミュレータに命令。
    - 実行結果を基に次の行動を決定（最大 10 回継続）。
