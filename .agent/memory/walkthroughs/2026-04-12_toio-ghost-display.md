# 実機のtoioゴースト表示機能の実装完了

実機のtoioが接続されている間、その現在位置をシミュレーションマット上に半透明の「ゴースト」として表示する機能を実装しました。

## 実施内容

### 1. UIの追加
- `index.html` に、通常のシミュレーション用キューブとは別に実機座標を表示するための `ghost-cube` 要素を追加しました。
- 「REAL」というラベルを表示し、実機の位置であることを明示しています。

### 2. スタイルの定義
- `style.css` に、実機らしさを強調するシアン色のボーダーと、ゆっくりとした明滅（パルス）アニメーションを追加しました。
- `pointer-events: none;` により、マウス操作を邪魔しないように設定されています。

### 3. 動的追従ロジックの実装
- `app.js` において、`toioBle.onIdUpdateCallback` を通じて実機の座標を毎秒数十回リアルタイムに受信し、シミュレータ座標系に変換してゴーストの位置に反映します。
- BLEが切断された際にはゴーストを非表示にする自動切り替えロジックを `updateToioUIState` に組み込みました。

### 4. シミュレータとの共存
- シミュレータ上のキューブは「目標位置」や「コード上の現在位置」を表示し続けるため、実機（ゴースト）がズレている場合に同期の状態を視覚的に把握できるようになりました。

## 動作確認のポイント
1. toio実機を接続すると、シミュマット上に半透明のゴーストが現れること。
2. 実機を手で動かすと、リアルタイムでゴーストが追従すること。
3. 実機を切断するとゴーストが消えること。
