# 設計判断ログ (Architecture Decision Records)

> 重要な設計判断を記録し、将来の変更時に「なぜこうなっているか」を追跡可能にする。

## ADR-001: ビルドレス構成の採用

- **日付**: 2026-04-09
- **状態**: 採用
- **決定**: バンドラー・トランスパイラを使用せず、Vanilla HTML/CSS/JS のみで構成する
- **理由**: toio制御のプロトタイピングが主目的であり、ビルド設定の複雑さを排除して即座に動作確認できる環境を優先した

## ADR-002: Ollama ローカル実行

- **日付**: 2026-04-09
- **状態**: 採用
- **決定**: 外部APIを使わず Ollama 経由でローカルLLMを使用
- **理由**: セキュリティ（APIキー不要）、レイテンシ（ローカル通信）、オフライン動作の確保

## ADR-003: シミュレータとBLEのマルチキャスト

- **日付**: 2026-04-10
- **状態**: 検討中
- **決定**: tool-executor がコマンドをシミュレータと物理BLEの両方に同時送信する
- **理由**: モード切替UIを排除し、常に両系統を同期させることでUXを簡素化
