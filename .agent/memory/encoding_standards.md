# エンコーディングに関する決定事項

## 概要
Windows環境におけるバッチファイル（.bat）とPowerShellスクリプト（.ps1）の共存において、コマンドプロンプトのロケール制限による文字化け・実行エラーが発生した。

## 決定事項
1. **バッチファイル (.bat)**:
   - 日本語を含む場合は必ず **Shift-JIS (CP932)** で保存する。
   - UTF-8 (BOMなし) で保存すると、日本語WindowsデフォルトのCMDでは文字化けし、不正なコマンドとして認識される可能性がある。
2. **PowerShellスクリプト (.ps1)**:
   - 日本語を含む場合は必ず **UTF-8 with BOM** で保存する（ルール7準拠）。
   - BOMがない場合、PowerShell 5.1環境で文字化けが発生する。
3. **変換ツール (fix.ps1)**:
   - 既存ファイルを変換する際は、読み込み側で `[System.Text.Encoding]::UTF8` を明示し、自動判定による誤読（UTF-8なしBOMをSJISと誤認するなど）を防ぐ。
