## BLE 関連

### BLE接続直後の切断
- **症状**: `navigator.bluetooth.requestDevice()` 成功後、GATT接続が即座に切れる
- **原因**: Characteristic取得前にGC等でデバイスオブジェクトが失われる可能性
- **回避策**: デバイス参照をクラスプロパティに即座に保持。接続確認ループの導入

## Ollama 関連

### CORS エラー
- **症状**: ブラウザから Ollama API にリクエストすると CORS ブロックされる
- **回避策**: `OLLAMA_ORIGINS="*"` 環境変数を設定して Ollama を起動する
- **状態**: 既知の仕様。`start.ps1` で自動設定済み

## エージェントループ関連

### toio の移動がループ・失敗する (2026-04-11)
- **症状**: 同じ場所で回転を繰り返したり、タスクが完了したと判定されない。
- **原因**: 
    1. AgentLoop が毎ステップ履歴をリセットしており、前回の行動（回転など）を忘れて「健忘症」になっていた。
    2. エバリュエーターが座標のみで判定しており、回転などの複合タスクが未完了と見なされやすかった。
- **修正内容**:
    - タスク開始時に一度だけ履歴をリセットするように変更（再試行の間は保持）。
    - エバリュエーターに直前のツール実行ログを渡し、コンテキストを含めた評価を実施。
    - プランナーに `move_to` の `angle` 指定を優先させるようプロンプトを調整。
- **状態**: [FIXED] — 会話 a49c116c で修正
