# start.ps1 ログ出力詳細化の計画 [DONE]

`start.bat` (経由の `start.ps1`) の実行状況をより詳細に表示し、ユーザーが現在のフェーズと進捗を正確に把握できるようにしました。

## ユーザーレビューが必要な事項
- `winget upgrade` の結果キャプチャ方法を変更することで、進行状況がリアルタイムに表示されるようになりますが、一部の出力が英語になる可能性があります（wingetの標準出力）。

## 変更内容

### [1/4] Ollama本体の確認
- `winget` での確認前に「最新パッケージ情報を取得中...」などのメッセージを追加。
- アップデートがある場合は、その旨を表示してから実行。

### [2/4] Ollamaサーバーの起動
- 起動待機中の秒数をカウントダウン表示、または進捗表示。

### [3/4] AIモデルの確認
- `ollama list` の実行開始を明示。
- モデルが見つからない場合のダウンロード（pull）実行時の説明を強化。

### [4/4] Webサーバーの起動
- 起動完了後に、アクセス先URLを目立たせて表示。

## 具体的なファイル修正

### [MODIFY] [start.ps1](file:///c:/Users/kouga/Projects/Web/toio-lab-web/start.ps1)
- `Write-Host` のメッセージを増量。
- `winget` の実行部分を、進行状況がわかるようにリファクタリング。

## 検証計画
- `start.bat` を実行し、各ステップでメッセージが期待通り表示されるかを確認する。
- Ollamaが最新の場合、アップデートがある場合、モデルがない場合などの各パスをシミュレーション（またはコードレビュー）で確認。
