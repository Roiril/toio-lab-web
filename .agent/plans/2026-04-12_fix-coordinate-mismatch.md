# シミュレーターと実機の座標系ミスマッチの修正

シミュレーション上のマット表示（CSS）と、内部で定義されている座標系（JS）の縦横比が逆転しているため、実機の位置とシミュレーター上の表示に歪みが生じています。これを修正し、正確な位置表示を実現します。

## ユーザーへの確認事項

> [!IMPORTANT]
> 現在の内部座標設定は **横長マット (304x216 単位)** を基準にしていますが、CSS（見た目）は **縦長 (5:7)** として描画されています。
> 今回、CSSを横長に修正しますが、これによってシミュレーターの見た目（マットの形）が横長に変わります。

## 修正内容

### 1. スタイルの修正

#### [MODIFY] [style.css](file:///c:/Users/kouga/Projects/Web/toio-lab-web/css/style.css)
- `.simulation-mat` の `aspect-ratio` を `5 / 7` から `304 / 216` (約 1.4:1) に変更。
- `background-size` を正確な正方形グリッド（50単位ごと等）に合わせて調整。
- `.sim-cube` のサイズを 10.6% から 7.9%（24/304相当）に縮小。

### 2. シミュレーションロジックの確認

#### [MODIFY] [toio-sim.js](file:///c:/Users/kouga/Projects/Web/toio-lab-web/js/toio-sim.js)
- `matToSim` / `simToMat` のロジックを確認し、CSSの変更に正しく追従することを保証。
- 境界チェック (max/min) を CSS の変更に合わせて修正。

## 検証計画

### 自動テスト（ブラウザ）
- シミュレーターが横長に表示されることを確認。
- 中心 (250, 250) や 四隅が一致するか確認。

### 手動検証
- 実機（toio）を接続して位置が同期するか確認。
