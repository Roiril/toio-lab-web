# 2026-04-13_fix-toio-stuck-move.md (Status: done)

## 概要
シミュレーション上では動くが実機が動かない場合があるバグ（特に同一座標への再移動や連続移動時に発生）を修正します。

## 変更点
### 1. js/toio-ble.js
- **Control ID の動的管理**: `moveTo` コマンドごとにユニークな ID (1-255) を付与し、応答を正確に待機するようにします。
- **角度の正規化 (New)**: 負の角度（-45度など）が指定された場合に 0-359 の範囲に正規化して送信し、パラメータエラーを防止します。
- **詳細なログ**: キューブからの応答コード（成功、中断、パラメータエラー等）をコンソールに出力します。

### 2. js/tool-executor.js
- **コマンド間ディレイの挿入**: コマンド送信前に 50ms の待機を入れ、BLE 通信の安定性を向上させます。
- **実行結果の通知**: `moveTo` の戻り値（0x00 以外）をチェックし、問題があればエージェントにフィードバックします。

## 検証計画
- `move_to` を連続して実行し、物理キューブがすべてのステップで追従することを確認する。
- 以前と同じ座標を指定した場合でも、現在の物理位置と異なる場合は正しく移動が開始されることを確認する。
