# UI/フロントエンド実装ルール

1. **スタイリング**: 新規コンポーネントを追加する際は、既存のCSS変数（`var(--accent-cyan)`等）とGlassmorphismクラス（`glass-panel`）を再利用し、デザインの統一性を保つこと。
2. **DOM操作**: イベントリスナーを追加する際は、多重登録を防ぐ仕組み（初期化関数内での一括登録など）を徹底すること。
3. **エスケープ処理**: ユーザー入力やLLMからの出力をDOMに挿入する際は、必ず `escapeHTML` 等のサニタイズ処理を経由させること。
