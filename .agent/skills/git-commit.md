# Git コミット規約

## メッセージフォーマット

```
<type>: <subject>
```

### Type 一覧

| Type | 用途 |
|---|---|
| `feat` | 新機能追加 |
| `fix` | バグ修正 |
| `refactor` | リファクタリング（機能変更なし） |
| `docs` | ドキュメントのみの変更 |
| `style` | コードスタイル修正（動作に影響なし） |
| `chore` | ビルド・設定ファイル等の変更 |
| `agent` | .agent/ ハーネスの変更 |

### 例

```
feat: シミュレータキャンバスにグリッド表示を追加
fix: BLE接続後の即切断を修正
agent: memory/known-issues.md にBLE切断問題を記録
```

## ルール

1. **Subject は日本語OK**（このプロジェクトでは日本語コミットを許可）
2. **1コミット1責務**: 機能追加とバグ修正を混ぜない
3. **WIP コミット禁止**: 動作する状態でコミットする
